# BlendUs 🍹
To launch the app:

**Terminal 1 — API:**
```bash
cd Prototipo-version/smoothies-api
php artisan serve 
```

**Terminal 2 — Frontend:**
```bash
cd Prototipo-version/blendus-frontend
npm run dev
```

Then open **http://localhost:4321**
